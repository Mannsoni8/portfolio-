# Mann Soni — Developer Portfolio

A modern, interactive developer portfolio built with **React, Tailwind CSS, and GSAP**.

## Tech Stack

- React
- JavaScript
- Tailwind CSS
- GSAP
- ScrollTrigger
- Remix Icons
- Vite

## Features

- Responsive design
- GSAP page animations
- ScrollTrigger animations
- Horizontal project scrolling
- Animated skills section
- Interactive project cards
- GitHub & LinkedIn integration
- Custom dark navy + cyan theme

## Projects

- **SkyMart** — E-Commerce Platform
- **BURROW** — AI Healthcare Platform
- **Productivity Dashboard** — Productivity Management
- **FineTrack Pro** — Personal Finance Dashboard
